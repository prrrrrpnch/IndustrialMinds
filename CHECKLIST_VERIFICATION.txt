1. ARCHITECTURAL OVERVIEW & SUMMARY OF CHANGES (as built)
--------------------------------------------------------------------------------
* ARCHITECTURE
  - The rule-based Cyber Agent and Physical Agent were KEPT as the hard
    PASS/DROP gate (HMAC, whitelist, rate, replay, bounds, rate-of-change,
    cross-register). They were not renamed or removed.
  - New CyberModel (models/cyber_model.py) and PhysicalModel
    (models/physical_model.py) run ALONGSIDE them.
  - New MultiModelPipeline (pipeline/multi_model_pipeline.py) runs the cyber
    branch (rules + CyberModel) and physical branch (rules + PhysicalModel)
    concurrently for every command, then the Orchestrator decides.
  - ML is advisory by default (MONITOR). IM_CYBER_MODEL_ENFORCE=1 lets a
    CyberModel threat flag also DROP commands (reason ML_ANOMALY).

* SCALE
  - 10 named machines (M1-M10) in docs/interfaces.MACHINES, Modbus holding
    registers 0-9. Added: AIR_COMPRESSOR, MIXER_SPEED, COOLANT_FLOW,
    EXHAUST_FAN, plus correlation rule COOLANT_STARVATION.

* MODELS (scikit-learn only)
  - CyberModel: Isolation Forest, 13 traffic features, unsupervised.
  - PhysicalModel: Random Forest regressor on a [60, 10, 3] sliding window
    -> RUL hours and Health Index 0..1 per machine.
  - Rationale, maths and measured results: MODELS_RATIONALE.md

* STRESS TEST & LOGGING
  - tests/test_middleware_efficiency.py, JSON + CSV under logs/, stdout via
    the Python logging module.

--------------------------------------------------------------------------------
3. ISSUES FOUND AND FIXED DURING VERIFICATION
--------------------------------------------------------------------------------
* sklearn per-call overhead (4-6 ms) -> packed tree inference, identical
  outputs, ~0.1 ms.
* PhysicalModel recomputed on every message (3.5 ms) -> vectorised features
  and 1 s refresh; capacity rose from 161 to ~1,100 msg/s.
* Replay-nonce purge scanned all nonces per command (O(n)) -> ordered expiry.
* Per-source state never pruned (memory grew with every new attacker IP)
  -> periodic idle-source sweep in Cyber Agent and CyberModel.
