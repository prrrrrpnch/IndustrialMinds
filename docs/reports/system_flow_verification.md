## How to watch this in Wireshark

A `capture.pcapng` of both legs is written next to this report. Open it and set **Edit -> Preferences -> Protocols -> Modbus/TCP -> Modbus/TCP port** to `5020,5021` (one range, both ports). Setting the preference twice does not work: the second value replaces the first and the other leg is then shown as *"Unable to classify as query or response"*.

Useful display filters:

- `mbtcp` - every Modbus frame
- `modbus.func_code == 16 && modbus.reference_num == 100` - signed command frames (the nonce is words 3-6)
- `modbus.func_code == 6 && tcp.dstport == 5020` - commands that were actually forwarded to the PLC
- `ip.src == <attacker> && tcp.dstport == 5020` - a write that bypassed the middleware

Artifacts (capture, logs, snapshot) are written next to the report in the run directory the tool prints.
