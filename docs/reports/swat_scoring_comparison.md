# Physical model v2 - the same alarms under every scoring scheme

Generated by `python -m benchmark.swat_protocol --from-report docs/reports/physical_training_report_v2_swat.json`. **Nothing was retrained or re-run.** The held-out SWaT test block (28,080 windows, 1,061 attack windows, 10 attacks, 37.53 benign hours) keeps its per-attack aggregates in the training report; only the way the alarms are COUNTED changes here.

Why: published SWaT scores of 0.8-0.9 mostly use point-adjust (one flagged window credits the whole attack) and often pick the threshold on the test labels. Below, the live model's alarms are scored every way, so a reader can compare with the literature and still see the strict number. Our threshold was fixed on the training data before the test block was scored.
